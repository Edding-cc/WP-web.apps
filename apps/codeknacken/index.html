Der Computer denkt sich einen Code aus vier Farben aus. Tippe Farben an, um eine Reihe zu füllen, und dann auf Prüfen. Ein voller Punkt heißt: richtige Farbe an richtiger Stelle. Ein Ring: richtige Farbe, aber an anderer Stelle. Eine Farbe in der Reihe antippen entfernt sie wieder.
